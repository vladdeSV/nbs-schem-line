Instructions

  1. Upload a Note Block Studio file (.nbs)
  2. Press the "Convert" button to convert and download the .schem file
  3. Open your .minecraft folder, and navigate to:
    config › worldedit › schematics, and place the .schem file there
  4. In Minecraft, type the following commands:
    1. /tp 0 130 0
    2. //schem load <your-schematic>.schem
    3. //paste -a IMPORTANT: You must include the -a, otherwise you will destroy the machine
